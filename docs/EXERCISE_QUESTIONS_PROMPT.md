## 1. What the feature is

On a practice ("exercise", "Reinforcement", "سرگرمی / سرگرمیاں", "Review", "I can do it") page, every
printed question gets a small button on the page, next to its heading:

| Button | `kind` | What happens when the child taps it |
|---|---|---|
| 🖍️ Colour / رنگ بھریں | `colour` | Only that question's part of the page opens in a big window. The child colours the pictures with the pencil. |
| ✏️ Write / لکھیں | `write` | Same window. The child writes on the printed lines or boxes only. Writing outside them is blocked and the child is warned. |
| 🔗 Match / ملائیں | `match` | A dot sits by each thing. The child draws a line from a dot to its pair. Right: the green line stays. Wrong: a red line appears, then disappears, with "Try again". |
| ⭕ Circle / دائرہ | `choose` | Tapping a correct answer rings it in green. A wrong answer flashes red. When all correct answers are found, the child gets a "well done" message. |
| ☑️ Checklist / چیک لسٹ | `tick` | **Automatic**: do not write these by hand (see §6). |

The finished examples to copy are **New Stemford English 3+** (`new-stemford-english-3`, 20 pages) and
**Stemford Urdu 3+** (`stemford-urdu-3`, 9 pages) in `books/questions.js`. Open both books in the reader and
try every kind of question before you start.

## 2. Files

  and `src/data/books.js` adds each page's questions to that page. Generated activity files are never touched,
  so re-running a book's generator does not remove the questions.
- `app.js`: `questionButton()` and `openQuestion()` implement everything. **Do not change `app.js`** unless

- `books/checklists.js` is generated by `tools/find_checklists.py`. Never edit it by hand.
- `books/game-crops.js` holds the Play-game crops (`tools/fit_game_crops.py`). It has nothing to do with this
  task. Leave it alone.
- `tools/question_check.py` makes the pictures you measure and check with (see §5). Its output goes to
  `tmp/question-check/`.

## 3. The question format (copy the helpers that are already in `books/questions.js`)

All positions are **percent of the page**: x from the left edge (0 to 100), y from the top edge (0 to 100).

```js
{ type: 'question', kind, title, say, button: { x, y }, crop: { x, y, w, h }, ...more }
```

- `title`: the question as printed (English for English books, the Urdu text for Urdu books).
- `say`: one short spoken instruction for the child.
- `button`: the top-left corner of the button. A button is about **17 wide and 4.8 tall**. Put it in empty
  paper beside the question heading. It must **never cover printed text, a picture or another button**.
- `crop`: the part of the page shown in the window. It must contain the whole question, with no half-cut
  word or picture at any edge. Leave out the next question and the "Teacher's Note" / page number where you
  can.
- `hint: { x, y }`: where a small pencil or crayon bobs until the child starts (colour and write questions).

Per kind:

- **write**: `lines: [{ x, y, w, h }, ...]`, one box round each printed writing place (the ruled lines next to
  a picture, an answer box, a dotted letter row). Measure the box round the ruled lines. The reader narrows a
  box that runs over a picture and widens it along the ruled lines, so the box does not need to be exact to the
  pixel, but it must be on the right lines.
- **match**: `dots: [{ id, x, y }, ...]`. Dots with the **same id are a pair**. Put each dot in empty paper
  right next to its letter or picture (below the top row, above the bottom row). If one letter may join from
  either side (Urdu 3+ page 48), give it a dot on each side with the same id. Ids must be unique per pair:
  when a letter is printed twice, use `'z1'` / `'z2'`.
- **choose**: `options: [{ x, y, w, h, correct, label }, ...]`, a box round each thing that can be tapped. Use
  the helpers `tap(x, y, correct, label)` (English letters), `harf(...)` (Urdu letters, bigger) and
  `tap(x, y, correct, label, 15, 12)` (pictures). There must be at least one `correct: true` in each group.
- **colour**: `parts: [...]`, `samples: [...]`, optional `skip: [...]`.
  - `part(name, [x, y, w, h], colours)`: a picture to colour. The box must go **round the whole outline**,
    with a little paper margin, and must not contain another picture. The reader colours the whole shape
    inside the outline (the lines inside a leaf do not stop it).
  - `pieces(name, box, colours)`: use this instead of `part` for a picture made of separate areas, each with
    its own colour: a ball's stripes, an umbrella's panels, a bus's windows, a rocket, a xylophone's bars,
    a boat's sails, utensils. A stroke then stays in the piece it starts in.
  - `seeds: [{ x, y, colour }]` on a `pieces` part gives one exact colour to each piece, as the sample shows.
    See the ball on English 3+ page 13.
  - `colours`: **only the colours the sample picture shows** (apple red, leaf green, stem brown). The reader
    shows only these colours in the palette and refuses any other colour with a warning ("Use red for the
    apple!"). Use the `C` constants: `C.red`, `C.orange`, `C.yellow`, `C.green`, `C.blue`, `C.purple`,
    `C.pink`, `C.brown`, `C.black`, and `MANY` for many-coloured objects.
  - `samples: ['apple', 'ball']`: **one for every picture in the question.** The reader finds the coloured
    picture with that name among the book's own Play-game targets and shows it small at the top ("Like
    this"). Find the names with the command in §5. A name that has no game picture is skipped. That is fine,
    but try to find the name the book really uses (Urdu names are Urdu words).
  - `skip`: boxes of printed answer boxes that lie inside the picture area, so they are never coloured.
- Letters to colour (the big outline letters "Colour and write the given letters"): one `part` per letter.
  The box must be **inside the letter's frame**, not on the frame, and the colour is the frame's colour. See
  `colourAndWrite()`. A letter with a long tail (j) needs a taller box.
- A question that is both "colour **and** write" (e.g. "colour and write the first letter") is **two
  questions with two buttons**: a `colour` one and a `write` one, both with the same crop.
